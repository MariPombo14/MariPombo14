Sou Técnica em Informática formada pelo SENAC e atualmente curso Análise e Desenvolvimento de Sistemas na Universidade Cruzeiro do Sul.

Minha trajetória é marcada por uma base sólida tanto em **desenvolvimento de software** quanto em **infraestrutura de TI**:
- **Desenvolvimento & Dados:** Criação de aplicações, modelagem e manipulação de Banco de Dados relacional via **MySQL Workbench** e prompt de comando (SQL), além de versionamento de código com Git/GitHub.

Busco continuamente expandir meus conhecimentos com foco em **Banco de Dados (SQL)** e **Desenvolvimento de Sistemas**, agregando valor através do trabalho em equipe, proatividade e capacidade contínua de aprendizado.
